# Kalycor Services — Redesigned

Premium dark security-services redesign built on the existing Next.js 14 project structure.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm start
```

## What changed

- Premium cinematic hero with stronger hierarchy and CTA treatment
- Cleaner glassmorphism navigation and mobile menu
- Redesigned service grid with a featured service and supporting cards
- More editorial About section with stronger typography and spacing
- Refined trust strip and Why Kalycor cards
- Stronger final conversion section
- Consistent navy / bone / restrained gold visual system
- Existing routes, service data, contact flow and content structure preserved
